================================================================================
ADMIN PAGES
================================================================================

1. Missions Admin Page
   URL: http://localhost:5000/admin-missions.html
   Features: Create, edit, delete missions with images

2. Satellites Admin Page
   URL: http://localhost:5000/admin-satellites.html
   Features: Create, edit, delete satellites with images
             Battery indicator, Type selection

3. Ground Stations Admin Page
   URL: http://localhost:5000/admin-groundstations.html
   Features: Create, edit, delete ground stations with images
             Location tracking, Uptime indicator

================================================================================
API ENDPOINTS
================================================================================

Upload Endpoints:
• POST   /api/uploads/missions              - Upload mission image
• POST   /api/uploads/satellites            - Upload satellite image
• POST   /api/uploads/groundstations        - Upload ground station image
• DELETE /api/uploads/:type/:filename       - Delete image

Updated Endpoints:
• POST/PUT /api/missions                    - Create/update with image
• POST/PUT /api/satellites                  - Create/update with image
• POST/PUT /api/groundstations              - Create/update with image

================================================================================
QUICK START
================================================================================

Step 1: Install Dependencies
$ cd backend && npm install multer

Step 2: Update Database
Run DATABASE_MIGRATION.sql or execute:
ALTER TABLE missions ADD COLUMN image_url VARCHAR(255);
ALTER TABLE satellites ADD COLUMN image_url VARCHAR(255);
ALTER TABLE ground_stations ADD COLUMN image_url VARCHAR(255);

Step 3: Start Server
$ npm start (from backend directory)

Step 4: Login to Admin Panel
Visit any of the admin pages above and login with admin credentials

Step 5: Upload Images
Create or edit entities and upload images through the web interface

STORAGE LOCATION
================================================================================

Images stored in:
• frontend/uploads/missions/
• frontend/uploads/satellites/
• frontend/uploads/groundstations/

Served via HTTP:
http://localhost:5000/uploads/missions/filename.jpg
http://localhost:5000/uploads/satellites/filename.jpg
http://localhost:5000/uploads/groundstations/filename.jpg

Database stored: image_url field contains the HTTP path

COMMON TASKS
================================================================================

Upload Image to Mission:
1. Go to admin-missions.html
2. Click "Create Mission" or edit existing
3. Fill form, click "Choose Image"
4. Select image file, wait for upload
5. Click "Save Mission"

Delete Image:
1. Edit entity with image
2. Click "Delete" button (deletes entity and image)
3. Confirm deletion

Change Image:
1. Edit entity
2. Click "Choose Image"
3. Select new image
4. Click "Save"

View Image:
1. Image displays in list view as thumbnail
2. Full size shown in edit modal
3. Accessible via URL: /uploads/type/filename.jpg

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "Cannot POST /api/uploads/missions"
Fix: Restart backend server (npm start)

Issue: "Unauthorized" error
Fix: Login as admin user, check JWT token in localStorage

Issue: "File size exceeds limit"
Fix: Use smaller image (<5MB), compress with TinyPNG

Issue: "Invalid file type"
Fix: Only image files allowed, convert to JPEG/PNG/GIF/WebP

Issue: Image doesn't display
Fix: Check browser console, verify file in uploads directory

See IMAGE_UPLOAD_GUIDE.md for complete troubleshooting guide
