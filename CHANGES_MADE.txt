DATA FLOW CHANGES
================================================================================

BEFORE:
User -> Dashboard (hardcoded HTML) -> localStorage -> No database sync

AFTER:
User -> Dashboard (dynamic HTML) -> api.js -> HTTP to Backend -> Database
   ^                                                              |
   |_____________ JWT Token in localStorage ____________________|

================================================================================
AUTHENTICATION FLOW
================================================================================

1. User logs in via login page
2. Credentials sent to POST /api/auth
3. Backend validates and returns JWT token
4. Frontend stores token in localStorage under 'user' object
5. All API calls include token in Authorization header: "Bearer TOKEN"
6. Backend validates token with jwt.verify()
7. Backend checks req.user.role for admin operations
8. Response: 200 if success, 403 if not admin, 401 if invalid token

================================================================================
API INTEGRATION DETAILS
================================================================================

Base URL: http://localhost:5000/api

All requests include headers:
{
  'Authorization': 'Bearer JWT_TOKEN',
  'Content-Type': 'application/json'
}

Response format (success):
{
  success: true,
  data: [...] or {...}
}

Response format (error):
{
  success: false,
  message: "Error description",
  error: "Detailed error"
}
