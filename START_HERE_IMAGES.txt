QUICK SETUP (3 STEPS)
───────────────────────────────────────────────────────────────────────────

1. UPDATE DATABASE
   Run this SQL:
   
   ALTER TABLE missions ADD COLUMN image_url VARCHAR(255);
   ALTER TABLE satellites ADD COLUMN image_url VARCHAR(255);
   ALTER TABLE ground_stations ADD COLUMN image_url VARCHAR(255);
   
   OR use: DATABASE_MIGRATION.sql

2. START SERVER
   $ cd backend
   $ npm start

3. VISIT ADMIN PAGES
   Login and start uploading images!

COMMON TASKS
───────────────────────────────────────────────────────────────────────────

To create mission with image:
1. Go to admin-missions.html
2. Click "+ Create Mission"
3. Fill in mission details
4. Click "Choose Image"
5. Select image file
6. Click "Save Mission"

To edit satellite image:
1. Go to admin-satellites.html
2. Find satellite and click "Edit"
3. Click "Choose Image" to upload new image
4. Click "Save Satellite"

API ENDPOINTS
───────────────────────────────────────────────────────────────────────────
POST   /api/uploads/missions          - Upload mission image
POST   /api/uploads/satellites        - Upload satellite image
POST   /api/uploads/groundstations    - Upload ground station image
DELETE /api/uploads/:type/:filename   - Delete image

TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────

"Cannot POST /api/uploads/missions"
→ Restart backend server

"Unauthorized error"
→ Login as admin, check browser localStorage

"File size exceeds limit"
→ Compress image to <5MB

"Invalid file type"
→ Use JPEG, PNG, GIF, WebP, or SVG

"Image doesn't display"
→ Check browser console and verify file exists

See IMAGE_UPLOAD_GUIDE.md for more help
