## 🚀 Quick Start Summary

### Prerequisites
- Node.js (v14+)
- MySQL 8.0
- Web browser

### Installation (3 Steps)

**Step 1: Database**
```bash
mysql -u root -p < database/astrolink_schema.sql
```

**Step 2: Backend**
```bash
cd backend
npm install
npm start
```

**Step 3: Frontend**
```bash
# Open: frontend/index.html
# Or: python -m http.server 8000
```

### First Use
1. Go to http://localhost:8000
2. Sign up as admin (admin@example.com)
3. Login and add your first mission
