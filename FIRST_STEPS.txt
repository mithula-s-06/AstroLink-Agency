================================================================================
                    FIRST STEPS TO GET THE SYSTEM RUNNING
                            (Follow in Order)
================================================================================

BEFORE YOU START:
- Make sure MySQL is installed and running
- Make sure Node.js v14+ is installed
- Make sure npm is installed
- Have the project folder open in your editor

================================================================================
STEP 1: SETUP DATABASE (2-3 minutes)
================================================================================

1. Open MySQL Command Line or Workbench
2. Copy and run this command:

   mysql -u root -p < database/schema_isro_complete.sql

   (It will prompt for password - enter your MySQL password)

3. Then run this command:

   mysql -u root -p astrolink_agency < database/isro_data_complete.sql

   (It will prompt for password again)

4. Verify it worked by running:

   mysql -u root -p astrolink_agency -e "SELECT COUNT(*) FROM missions;"

   Should show: 40+ missions

✅ Database is now ready with 40+ ISRO missions!

================================================================================
STEP 2: SETUP BACKEND (2-3 minutes)
================================================================================

1. Open a NEW Command Prompt/Terminal window

2. Navigate to backend folder:
   cd backend

3. Install dependencies:
   npm install

4. Create .env file with these contents (copy from .env.example):
   
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=      (your MySQL password)
   DB_NAME=astrolink_agency
   PORT=5000
   NODE_ENV=development
   CORS_ORIGIN=http://localhost:3000

5. Start the backend:
   npm run dev

   You should see:
   ✓ Database connected successfully
   Server running on http://localhost:5000

✅ Backend is now running!

================================================================================
STEP 3: SETUP FRONTEND (2-3 minutes)
================================================================================

1. Open ANOTHER NEW Command Prompt/Terminal window

2. Navigate to frontend folder:
   cd frontend

3. Install dependencies:
   npm install

4. Start the frontend:
   npm start

   Your browser will automatically open http://localhost:3000

   You should see the AstroLink Agency app load!

✅ Frontend is now running!

================================================================================
STEP 4: QUICK TEST (1 minute)

   - MySQL running (database)

================================================================================
IF SOMETHING DOESN'T WORK
================================================================================

DATABASE NOT CONNECTING?

1. Is MySQL running?
   - Windows: Check Services (press Windows+R, type services.msc)
   - Or open MySQL Workbench

2. Is password correct in .env?
   - Update DB_PASSWORD with your actual MySQL password

3. Did the schema/data import succeed?
   - Check: mysql -u root -p astrolink_agency -e "SELECT COUNT(*) FROM missions;"
   - Should return 40+

BACKEND WON'T START?

1. Is Node.js installed?
   - Check: node --version (should be v14+)

2. Did npm install complete?
   - Delete node_modules folder
   - Run: npm install again

3. Is port 5000 already in use?
   - Try: netstat -ano | findstr :5000
   - Kill the process or change PORT in .env

FRONTEND WON'T LOAD?

1. Is backend running?
   - Check: http://localhost:5000/api/health
   - Should return: {"status":"OK"...}

2. Is npm install complete?
   - Delete node_modules folder
   - Run: npm install again

3. Is API URL correct?
   - Check: frontend/.env has REACT_APP_API_URL=http://localhost:5000/api

COMMON COMMANDS YOU'LL USE
================================================================================

Start Backend:

Start Frontend:

mysql -u root -p astrolink_agency -e "SELECT COUNT(*) FROM missions;"

Check Backend Health:
curl http://localhost:5000/api/health

Kill Process on Port:
Windows: taskkill /PID <PID> /F
Mac/Linux: kill -9 <PID>

Restart Everything:
1. Stop frontend (Ctrl+C in frontend terminal)
2. Stop backend (Ctrl+C in backend terminal)
3. Restart backend: cd backend && npm run dev
4. Restart frontend: cd frontend && npm start
